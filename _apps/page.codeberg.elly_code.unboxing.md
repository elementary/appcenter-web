<p>Handle for you the installation of downloaded debian packages, along with their dependencies, with a double-click</p>
<p>Debian packages are the format used for system components. A lot of applications are distribued in this format, despite or because of the lack of sandboxing.</p>
<p>Make sure to install only packages that are intended for your version of elementary OS:</p>
<ul>
<li>elementary OS 7: packages for Ubuntu 22.04 LTS</li>
<li>elementary OS 8: packages for Ubuntu 24.04 LTS</li>
</ul>
<p>Please do NOT file issues against elementary OS for any issue encountered installing packages from this. Debian packages are officially unsupported.</p>
<p>This app is made lovingly and without any LLM intervention</p>
