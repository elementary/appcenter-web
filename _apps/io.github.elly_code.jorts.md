<p>Neither jeans nor shorts, just like jorts! A thoughtful little sticky notes application, to display any sort of short term information on your screen.</p>
<p>Features include:</p>
<ul>
<li>Colourful: Eleven pretty pastel themes</li>
<li>Cute: Each new note has a funny or cute random (editable) title</li>
<li>Thoughtful: Jorts does its best to be comfortable to use, always!</li>
<li>Private: Try the scribbles mode!</li>
</ul>
<p>Windows installers are also available, and require no admin rights. So you can even use this at work!</p>
<p>This app is made lovingly and without any LLM intervention. </p>
